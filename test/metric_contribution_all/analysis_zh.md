# 全部配对的五指标贡献分析

按用户要求，不限制 GeneB、不分 stable_reference；只分析全部 206 对五项分数均完整的配对。before=错误结构，after=正确结构。CSQ 总分和 label 不参与。使用 2000 次成对 bootstrap，随机种子 42。

## 主要结果

| 指标 | 平均纠错提升 | 单指标 AUC | 去掉后的 AUC | AUC 损失（完整−去除） |
| --- | ---: | ---: | ---: | ---: |
| CDS_number_score | 0.2065 | 0.8663 | 0.9618 | -0.0031 |
| Phase_match_score | 0.1960 | 0.8937 | 0.9624 | -0.0037 |
| CDS_length_score | 0.2949 | 0.9518 | 0.9591 | -0.0004 |
| Intron_site_score | 0.2436 | 0.9528 | 0.9583 | +0.0004 |
| Total_length_score | 0.2740 | 0.9627 | 0.9515 | +0.0073 |

五项等权平均组合的完整 AUC 为 0.9587。

- CDS_length_score 的纠错响应幅度最大，但去掉它后，等权组合的 AUC 几乎不变。这不等于它没有信息；其他指标可能提供了相近信息。
- Total_length_score 的单指标区分能力最高，且在当前固定组合中补充贡献最大。去除导致 AUC 下降约 0.00726，配对 bootstrap 95% 区间约 [0.00390, 0.01097]。
- CDS_number_score 与 Phase_match_score 单独具有区分能力，但在当前五项等权组合中，移除后 AUC 略升。这只能说明它们在当前样本/等权规则下未带来增益，不能据此认定对所有错误都无用或应永久删除。
- Total_length_score 单独的 AUC 略高于五项等权组合，提示等权组合并非必然最优；本次没有学习权重或训练分类器。

## 图的解释

metric_contribution.png/.pdf 已改为一组点与水平区间，不连接点、不叠加两个群体。三列依次为纠错平均提升、单指标 AUC、去除后 AUC 损失；水平区间是 95% 成对重采样区间。

第三列大于 0 表示移除后区分能力下降；小于 0 表示移除后反而改善；区间跨 0 表示当前重采样下方向不稳定，不等于证明无作用。各项不是贡献百分比，不要求相加为 100%。

以上为 add_exon 这批记录的描述性分析，不能直接推广到其他错误类型。区间没有进行多重比较校正。所有原始配对、缺失与样本范围见 paired_metric_scores.tsv 和 audit.json。
